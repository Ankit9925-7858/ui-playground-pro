
# UI Playground Pro

A modern browser-based UI development playground built with **React + Vite + Supabase**. Users can create, edit, preview, save, import, and export frontend projects from one workspace.

## 🚀 Features

- ⚡ Live HTML, CSS and JavaScript preview
- 🎨 Modern responsive user interface
- 🌙 Light and Dark mode
- 🧩 Component library for quickly adding UI elements
- 💾 Manual save and autosave support
- ☁️ Cloud project storage using Supabase
- 🔐 User authentication
- 📁 Create and manage multiple projects
- ✏️ Rename projects
- 🗑️ Delete projects
- 📥 Import projects
- 📤 Export projects
- ↩️ Undo and Redo functionality
- 📱 Responsive desktop, tablet and mobile preview
- 🔄 Project data persistence for signed-in users
- 🔗 Shareable project-based routing
- 🛡️ User-specific project access and database security
